# Assignment and rubric map

The creative project combines the author's personal writing with an interactive operating-system metaphor. This guide maps the supplied rubric to the finished website; it is not a grade prediction.

| Rubric area | Where it is addressed |
| --- | --- |
| Meaningful connections to personal wellbeing | “What helps” connects support from a partner and friends, learning and academic ambition, restorative walks, and Vancouver's natural environment. |
| Broader influences | “Beyond me” considers the competitive university and technology-industry environment, comparison with peers, institutional and hiring pressures, economic uncertainty, and unequal access to public green spaces. |
| Clear project description | The author's 221-word description explains the four themes, the computer-system metaphor, the workload interaction, and the central insight. It is linked from the header and closing section. |
| Meaning-making and insight | The reflections explore the significance of relationships, the tension between ambition and pressure, guilt around rest, and the difference between recovery and avoidance. |
| Authenticity | All seven reflection areas and the supporting description use the author's supplied writing. The short introductory and wider-connection passages draw only on those experiences. |
| Recognising struggling and thriving | Three signs of doing well and three signs of struggling are followed by an account of productivity concealing exhaustion and a change in how wellbeing is evaluated. |
| Originality, effort, and intentional choices | A clear reading order gives the personal reflections priority. The System Monitor makes the relationship between workload and other resources visible, and the closing summary connects the themes. |

## Creative choices

The OS metaphor connects the tendency to optimise output with the need to attend to the whole person. The resource bars change together so visitors can explore that relationship. The values are explicitly fictional and are not presented as a health assessment.

Text, restrained colour, readable typography, and generous spacing support attention to the author's voice. The navigation provides direct access to all four chapters and the supporting description. The interface also supports keyboard interaction, mobile reading, and reduced-motion preferences.
