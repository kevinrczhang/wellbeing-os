# Assignment and rubric map

This is an authoring guide, separate from the creative component. It maps the supplied assignment and rubric to the redesigned website. It is not a grade prediction.

| Rubric area | Where the design addresses it | What still requires the author's input |
| --- | --- | --- |
| Meaningful connections to personal wellbeing | “What helps” connects connection, purpose, recovery, and environment; the workload experiment makes tradeoffs visible. | Specific lived moments and why they matter personally. |
| Broader influences | “Beyond me” connects reciprocal care, community, and the earth, then considers institutional expectations, money/time/access, and culture/belonging. | One context that actually applies, a concrete effect, and a realistic response that acknowledges limits to individual control. |
| Clear project description | `/project-description/` directly explains how the journal, operating-system metaphor, interaction, and composition represent wellbeing. It is linked in the header and closing section. | Personalise the interpretation after adding real experiences; replace the paragraph about unfinished personal content. |
| Meaning-making and insight | Each journal entry connects a practice to its significance. “My signals” distinguishes output from wellbeing, and the changed-understanding prompt invites a before/experience/now reflection. | Reflect critically on an experience, tension, mistaken assumption, or change in understanding, rather than supplying a list of favourite activities. |
| Authenticity | All absent personal experiences are marked, photographs are labelled samples, and example signals are identified as starting points. | Replace prompts and sample observations with the author's voice. The current draft cannot demonstrate authentic autobiographical reflection on its own. |
| Recognising struggling and thriving | Contrasting signals and the resource experiment show how high productivity can coexist with less connection and recovery. | Name the author's actual signals and describe what recognising them changes. These are reflections, not diagnoses. |
| Originality, effort, and intentional choices | The OS metaphor survives through linked resource bars and a system summary. The photo journal and four-chapter reading order make relationships visible without requiring window management. | Original personal writing and, where appropriate, personal photographs. Only the instructor can assess originality relative to prior work. |

## Why the interface changed

The old overlapping windows hid the reading order and required visitors to learn desktop controls. The revised project keeps every chapter on one page, provides four direct chapter links, and gives the supporting description a permanent link. A single meaningful experiment carries the OS metaphor. Restraint, large photographs, readable type, and generous spacing support attention to the story.

## Before submission

1. Supply the four short journal reflections using real moments and consequences.
2. Replace the example signs with personal observations; explain a sign previously missed.
3. Explain a change in understanding using an actual experience.
4. Describe a wider influence and a response, including what cannot be changed individually.
5. Replace sample photography or clearly retain attribution if illustrative images are permitted.
6. Revise the supporting description to reflect the finished project and keep it at 200–300 words.
7. Add APA 7 references if outside sources are used or the course requires them.
8. Remove draft notices only after the placeholders have been completed.
